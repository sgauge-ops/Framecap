# Framecap

Framecap is an experimental Linux Vulkan layer that provides an FPS cap, an
overlay, and automatic FPS regulation.

- [Installation and Steam setup](documentation/INSTALL.md)
- [Configuration and keyboard shortcuts](documentation/CONFIGURATION.md)
- [Documentation index](INDEX.md)
- [Known limitations and pending work](TODO.md)
- [Changelog](CHANGELOG.md)

The automatic algorithms are experimental. GPU load telemetry currently
supports AMD; global keyboard shortcuts require X11 or XWayland.
